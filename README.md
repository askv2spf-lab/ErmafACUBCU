# Діагностика GP 70 / GP 95 (PWA)
1. Завантажте вміст архіву в корінь репозиторію GitHub.
2. Settings → Pages → Branch: main / root.
3. Відкрийте посилання, «Встановити застосунок» / «На головний екран». Працює офлайн після першого відкриття.
4. Зображення вузлів — у папку `images/` (gas.png, gas1.png, gas2.png … = карусель). Переглянуті зображення кешуються для офлайну.
Після змін піднімайте версію `C` у sw.js.
